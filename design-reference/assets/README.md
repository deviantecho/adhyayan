# NCERT Study Companion visual assets

Place these four files in the project at:

design-reference/assets/

- science-hero.png
- mathematics-hero.png
- science-quote.md
- mathematics-quote.md

The hero images are intentionally text-free and leave the left side visually
quiet so the React chapter title can be rendered as real HTML.

The quote files distinguish chapter statements from verbatim quotations so the
UI does not imply that an editorial sentence is an exact NCERT quote.
